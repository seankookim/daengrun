Where the honesty law bites

The forbidden drawing is a greyed-out text field. It is a control's silhouette with no route behind it — the dead-button class — and it also lies about the cause: the reader is not temporarily blocked, they are on a different rung. All three variants replace the seat rather than dimming it.

The one accent per frame

①the 채팅 tab's underline. The plate is ink, the CTA is coral.
②the 채팅 tab's underline. The boundary is ink at 2.5px — the masthead rule's weight, deliberately.
③the viewer's own rung. The tab underline drops to ink so the accent is not spent twice.

Why these two are outside the pick

ⓒ is what club_my_chat_writable already returns true for, with the composer that already ships (api.ts:4513 insert · 4547 realtime). Nothing in the ruling changes it; re-drawing it three ways would ask Sean to pick between three copies of the same screen.

ⓟ is the ruling's own second sentence — 「roster and pictures, any one should be able to see it」 — and it has no chat element at all, so there is no boundary to draw. The one line at the foot (대화는 신청한 사람부터 볼 수 있어요) is a statement of fact, not a locked control: it has no border, no fill and no chevron.

🔴 The one gap inside ⓟ

「any one」 is not what the board's gate says today. club_session_board (0136:70-80) returns zero rows unless the caller is a club member or has shell access ≠ none. A true stranger holding a link sees an empty screen, not a roster.

The only anon-public surface that exists is club_pack_map_roster (0160:565-566, granted to anon), and its people array is empty unless _club_pack_window is open — a band that begins two hours before the session. So ⓟ is true for a club member browsing beforehand, and owed for a stranger. Widening the board's gate is a separate slice with its own disclosure review — and note ruling §5 narrowed the delegation board for strangers in the same breath, so the two boards must be kept apart when that slice is written.

Pictures

Bound to dog_photo_url / runner_photo_url (0136:43,48). The frames draw the cells at their real aspect with the dog's name in them — a lab has no photos, and a stock image would be the fabrication the house forbids.
