Recommended pairing — Ⓐ② Night Stub × Ⓑ④ Stub

Why they belong together: both are the ticket/stub grammar the app already owns. The hero center tears a stub to start a run; the club card is a stub with the D-day torn off. One shared metaphor, so the home screen reads as one document instead of four widgets — and the night club card sits far enough down the scroll that it never fights the white hero for attention.

Safe alternative if the dark island feels risky on device: Ⓐ① Departure × Ⓑ④ Stub — the club card keeps the paper feed intact and still fixes the "bland" complaint with type scale alone, which is the cheapest possible fix and the least likely to regress on small screens.

Highest-ceiling / highest-cost pairing: Ⓐ③ Passport × Ⓑ③ Gauge — the most distinctive, but it adds an MRZ encoder and puts a second meter inside a screen that already has one. Only worth it if the club is meant to feel like a separate product surface.

Do-not-refactor respected in all four Ⓑ variants: the GO lives inside the existing center layer, which keeps crossfading on opacity alone; every proposed collapse echo is a new absolute sibling animated with transform/opacity only. No measured layout, no height animation, no change to the 54-dot ↔ progress-line crossfade.
