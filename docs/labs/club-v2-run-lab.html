CLUB MODE A · ADDENDUM A3 · NEW SCREEN · 4 FRAMES · SEAN PICKS BY NUMBER

The live screen for a club participant who is not a paid runner — an owner running their own dog (동반, joined free under 「무료로 크루 참가」) or a dogless crew member — per docs/plans/2026-08-25-club-mode-a-addendum.md §2/§3. Every frame obeys the same four laws: the course polyline is always visible (the runner "needs to see where to go at all times"), the crew appears as board states only (러닝 중 · 도착 · 귀가 중 — never live GPS of others), my finish closes only my record (즉시 해제 — no host dependency), and the SOS/case entry sits bottom-left at the thumb, throughout. Variants ①–③ are three personalities for the same bound data; frame ④ is the dogless-crew rendering of the picked layout.

The map is the screen — full-bleed course polyline with everything else floating on glass chrome, the strongest reading of Sean's map law. Stats ride one glass slab, the crew collapses to a state summary chip, and the dog card is a floating strip above the SOS/finish row.

Questions this lab cannot decide

  1. ①, how much map may the chrome cover? The map-dominant frame floats ~130pt of glass over the route. If the crew chip collapses to a dot-count only (no state breakdown), the course wins back a band — but the states are the whole crew story. Which loses?
  2. ②, does the run view fork inside club/run/[sid] or stand alone? The addendum's 🔵 is a participant mode of the existing screen (map shell + GPS watcher reuse); ① and ③ pull harder toward a separate screen. The mode fork is new code either way — this is an architecture pick, not a design pick.
  3. ③, is 최민재's 위탁 2마리 line acceptable on the crew board? It is board-state data, not GPS — but it tells every participant which runner holds whose dogs. The alternative is 러너 with no count.
  4. All frames, the finish sheet's fitness line. 「수리의 체력 카드에 반영돼요」 asserts addendum §3.3's 🔵 (self-runs move the 체력 card via fetchFitness union). If Sean rules self-runs out of 체력, this sentence — drawn in ② and ③ — must come out with it.
