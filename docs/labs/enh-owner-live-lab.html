Owner live + meetup — enhancement lab

enh-owner-live-lab · 2026-08-24 · 4 screens · 12 variants · new hexes: 0 · new columns / tables / RPCs: 0

Four screens the owner passes through in one booking: finding a runner → handing the dog over → watching the run → picking the course for the next one. Every frame below is a restyle or a re-arrangement of code that exists today. Where a variant prints a value, the field that would bind it is named under the frame; where a variant needs something the client does not carry yet, the frame says so and the cost line prices it. Nothing here needs a migration.

What this lab refuses to draw

No new clock on radar. owner/radar.tsx's own header says it: “애니메이션 ≠ 카운터 — 이 화면에는 숫자가 하나도 없다.” The elapsed M:SS and the 10-minute amber nudge were deliberately deleted; none of R①–R③ brings either back.
No stage-machine change on meetup. owner/meetup.tsx is frozen (DESIGN.md §9). M①–M③ are paint, slot content, and conditional density. None of them writes a stage, moves a poll, touches confirmHandoff, or re-orders the hydration gate.
No "fix" to radar's two-flag lifetime. radar.tsx's aliveRef (mount — gates state writes) and focusedRef (focus — gates navigation, alerts, haptics) are deliberately two different flags: a router.push to a runner profile leaves this screen mounted-but-unfocused, and collapsing them re-introduces the bug where a confirmation 1.8s later replaced the profile the owner was reading. Untouched in every variant.
No runner-position claim on the meetup plate. PickupMap is a static pin with every gesture disabled — it has never shown where the runner is, and M③ does not start.

Reading the frames

Frames are 390px wide, which is 1:1 with points on the target device — so the 14pt detail floor is literal here: any text you can measure at 14px in a frame ships at 14pt. The only sub-floor type in this lab is the seal band's OWNER/RUNNER latin letterspaced caps (8.5pt), which is the existing sanctioned kicker exemption, already in the shipped file.
Black Han Sans budget: exactly one use in this whole lab — meetup's 인계 확인 title, where it already is. Radar, live and course-map carry no display font today and none of their variants adds one.
Coral budget: radar spends it on the core disc + nomination links, meetup on the CTA dock, course-map on the sheet CTA. owner/live.tsx deliberately has zero coral fills (its own comment: “예산은 상한이지 할당량이 아니다” — the emphasis is carried by the ink LIVE pill); L①–L③ keep it at zero.
