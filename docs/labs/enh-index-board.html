Ten enhancement labs, fifty-three screens, one pick sheet

index board · 2026-08-24 · 10 labs · 53 screens · 142 variants · 0 new hexes

Ten enhancement labs were drawn against the shipped screen source, one cluster each. This board exists so a pick can be made in one pass: the pick sheet below lists every screen once, with its numbers, so the answer can be written straight down the page — “owner/home ②, runner/home ①”. Everything else here (the lab cards, the cost sheet, the open questions) is reference for when a number is not obvious.

Read this before picking

These are mocks. Nothing in any lab is bound to real data. Every number, name, time and photo inside a phone frame is a fixture shaped like its real field — bookings.scheduled_at, runs.actual_km, ledger_items.amount — and the labs annotate which field would bind it. This is the sanctioned mockup arena (CLAUDE.md §Honesty: “HTML labs in docs/labs/ are the sanctioned mockup arena”). Implementation binds real fields only. A picked variant that cannot reach a real field either loses the element or moves onto the cost sheet below — it never ships with the fixture.

Nothing here was rendered on a simulator. Contrast figures quoted inside the labs are WCAG relative-luminance computations from theme.ts hex values, not device readings. Layout fit on a 390pt device is flagged as unmeasured wherever a lab was unsure — those are five-minute simulator checks, not findings.

Zero new colours across all ten labs. The style freeze (no new aesthetics until 50 paying dogs) held: every hex in every frame is already in theme.ts or already shipping in the screen file being redrawn.

⑤HOW TO READ A ROWand what happens after a number is written

Numbering

Numbering is per-lab, not global. Four labs prefix their numbers with a screen letter (R①, M②, C①, S②) because the same screen letter recurs in that lab’s cost table; four use bare ①②③④ per screen; the runner run flow numbers ①–⑫ straight through its four screens. The pick sheet prints the number in the exact form its lab uses, so “club S②” or “runner-run ⑦” is unambiguous on its own.

What a pick means

A number selects an argument, not a pixel spec. Implementation reads the lab’s frame, binds the real field named in the annotation beside it, and drops anything it cannot bind. A variant that reached the cost sheet does not become a client change because it was picked — it becomes a slice with a migration or a new read in front of it, and the migration goes through /autoplan and the SQL harness before the screen is touched.

owner/fitness’s collapsing hero (records ①②③ — restyle only; no height/layout animation, no backgroundColor animation, the 36-dot ring layers stay hardware-textured).
