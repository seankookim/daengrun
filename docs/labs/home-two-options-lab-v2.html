GoState뜻히어로가 보여주는 것왜
none오늘 아무것도 없음두 옵션 — 지금 찾기(코랄) + 예약하기결정 둘. Hick’s.

confirmed러너 확정, 시간 전알림 줄(세이지) “19:30 · 민준 러너 확정” + 예약하기 하나만할 일은 기다리는 것. 하나 더 잡는 건 가능하니 예약하기는 남는다.
handoff러너 이동 중 / 인계 확인 필요알림 줄(코랄 = 내 차례) “러너 도착 · 인계 확인 ›” — 버튼 없음지금 이 순간 해야 할 일이 하나뿐이고 그건 새 예약이 아니다. 코랄은 “당신 차례”.
active러닝 중라이브 위젯이 존 전체를 대체 — 버튼 없음개가 밖에 있다. 화면의 유일한 관심사.

색은 GO 디스크의 법을 그대로 물려받습니다(CLAUDE.md): 코랄 = 내 차례 · 블루 계열 = 대기 · 세이지 = 준비됨. 디스크는 은퇴해도 그 어휘는 남습니다 — 사용자가 이미 배운 것이라서(Jakob, 우리 앱 안에서의).
