## ⚠ Before anything publishes

1. **Type is a stand-in.** Black Han Sans is not installed on this machine, so Korean display type
   fell back to Apple SD Gothic Neo Bold and Latin to Arial Black. Install Black Han Sans and re-run
   — nothing else in the script changes. The baked-in headlines on the source posters are unaffected;
   this only concerns type *I* set (tile 1, the type cards, the slide text, the disclosure band).
2. **Swoosh pass.** No file used here carries a visible Nike swoosh — that is why tile 1 is *built*
   rather than cropped from `REMOVE NIKE.png`. Two `dumb/` files are used (TS-2 slides 4 and 5) and
   both need a look before upload, because `dumb/` holds retouched and un-retouched near-duplicates.
3. **Everything photographic here is AI-generated** and carries `콘셉트 이미지 · 서비스 준비 중` in
   frame. Do not remove it, and repeat it in the caption. The type cards carry no such band because
   they make no claim about a scene.
4. **No App Store screenshots exist and none are faked here.** Store screenshots must be captured
   from the real app (`campaign-concepts.md` PART 4 forbids AI on that surface) and no build has ever
   been produced. That set gets made the day a build runs on a device.

## What the numbers on the posters mean

Several source posters carry a baked-in readout (`8:34/km · 5.3km`, `9:12/km · 6.8km`,
`8:08/km · 4.6km`, `7:48/km · 6.2km`). **None of them is a customer's run** — there are zero
completed bookings. They are concept figures inside concept images, which is exactly why the
disclosure band is not optional on those frames.
