종료 사유

보호자 요청으로 종료되면 요금은 예약하신 그대로 청구돼요 — 남은 거리만큼 줄어들지 않아요.

Why a modal is right here. impeccable puts modals on the refuse list — "a modal for a task that needs neither interruption nor protected focus". This task needs both: it is irreversible, it charges the full fare, and it sends the reason to the runner. impeccable ios.md: "Deliberate modality. Sheet for a focused dismissible sub-task … Clear Cancel/Done." The dismiss label being a human sentence (계속 지켜볼게요) rather than 취소 is the best thing about this sheet. The fare sentence is not hidden. taste-skill §4.9 COPY SELF-AUDIT and DESIGN.md §7 both require the real consequence to be stated.

What this lab deliberately did not do

1. The LIVE dot does not pulse. Every skill offers a pulse as a premium device (soft-skill §5, taste-skill §5). This house forbids it. DESIGN.md §6: the GO disc breathes only during matching and LIVE — "idle에 돌리면 거짓 모션. No idle loops, no fake progress." A pulsing dot asserts "just updated"; pulsing over a 90-second-old fix is a lie. taste-skill §9.F: "ZERO decorative status dots by default … Only acceptable when conveying real semantic state." Ours conveys real state and survives — but earning the dot does not automatically earn the animation. 2. No video surface. StreamSlot renders null today. Korean strings existing in a file is not the same as a UI existing. 3. No glass, in any variant, including the departure. The overlays are opaque white with a 1px border (①②) or an opaque card with a shadow (③). DESIGN.md §7c · impeccable craft floor · HIG checklist C5. And outdoors, translucency is functionally wrong on top of everything else. 4. The progress bar only appears when the target is known. It is km / targetKm, not decoration, and with no booking km it is not drawn at all. impeccable craft floor refuses "sparklines, progress rings, and soft-shadowed rounded rectangles standing in for content"; taste-skill §9.F refuses filled-track scoring bars. A real ratio with a real denominator is neither.
