TikTok is a new channel for this brand — no doc covered it. §1–§3 define the rules; §4 is six
production-ready slideshows built only from assets that already exist.

---

## 1. Why slideshow and not video

We have 67 finished poster-format images and zero seconds of usable footage. Photo mode is the only
format where that is an advantage rather than an excuse. It also fits the one-founder constraint that
governs every other channel: a slideshow is assembled in 15 minutes, a video is a shoot day.

Photo mode is not a lesser format on TikTok — it is served in the same feed, it holds the viewer
per-slide instead of per-second, and swiping back is a native gesture, so a *reveal* structure
(question → evidence → answer) outperforms a linear one.

## 2. Format spec — hard

| Item | Value | Why |
|---|---|---|
| Slides | 6–8 | Under 6 there is no reveal; over 8 the drop-off outruns the payoff. |
| Canvas | 1080×1920 | Source assets are 1024×1536 (2:3). **Pad top/bottom with `#0F1D13`, never crop the sides** — cropping to 9:16 eats 16% of the width and that is where the headline type lives. |
| The pad band | bottom band carries the wordmark left, the disclosure right | Turns the letterbox into the disclosure surface, so a cropped caption can never remove it. |
| Slide 1 | hook, ≤12 Korean chars on screen, no logo | It is the only slide most people see. |
| Text per slide | one idea, ≤2 lines | The image already carries typography; TikTok text is a second layer, not a repeat. |
| Sound | **TikTok Commercial Music Library only** | A business account cannot legally use the general catalog. This is a real restriction, not a preference. |
| Caption | ≤2 lines + 4–6 hashtags | |
| Emoji | zero | Brand rule, applies here too. |
| Cover | slide 1 | |

## 3. TikTok-specific brand rules

1. **The disclosure travels in the frame.** Every AI-generated slide carries `콘셉트 이미지 · 서비스
   준비 중` in the bottom pad band, `#D8DAD2` at ~1.6% of frame height, plus the first line of the
   caption. TikTok crops captions in-feed; the in-frame line is the one that always survives.
2. **"산책" only in comparison.** Never as a name for what we do.
3. **No third-party logos.** Several assets still carry a Nike swoosh — see §5. That is a hard block,
   not a nitpick: a trademark in a paid-adjacent feed is the cheapest possible lawsuit.
4. **Trust content is type-only.** TS-4 (기준) and any 안전 기준 slideshow use type cards on
   `#FFFFFF`/`#EFF1EC` with a hairline — no red headline, no route glow, no photography.
5. **Runner and owner dialects never share a slideshow.** Mixing them makes the runner content read
   as a 알바 공고 and the owner content read as a recruiting pitch.
6. **Comments are the channel's real asset.** Every "우리 개도 그래요" comment is a validation
   interview we did not have to schedule (`launch-checklist.md` §4 — still 0 interviews). Reply to
   all of them; screenshot the recurring ones into the FAQ highlight.

## 5. ⚠ Asset gate — swoosh check before anything publishes

Multiple assets carry a **Nike swoosh**, and the filenames say the founder already knew:
`REMOVE NIKE.png`, `dumb/remove nike logo.png`. Confirmed by eye:
`[3]`, `[40] 도그스로바꿔.png`, and much of `dumb/` — `[49] [50] [52] [55] [56] [57] [58] [59] [66]`.

**Rule: every asset gets a swoosh/logo pass before it enters a slideshow.** Treat `dumb/` as a reject
bin by default (`[45] [47]` are the exceptions used above and both need the pass). Near-duplicate
files differ only in retouch state, so "the clean one" and "the contaminated one" have almost the same
name — check the file you are actually about to upload, not the one you remember checking.

## 6. Cadence and measurement

Two slideshows a week, 21:00. Order: **TS-1 → TS-3 → TS-5 → TS-2 → TS-4 → TS-6**. TS-3 goes second
because supply is the bottleneck and TS-1 only exists to prove the account is worth following.

Judge on **완주율(마지막 슬라이드 도달)**, **저장**, **공유**, and **프로필 → 링크 클릭**. Not on views.
UTM every link: `?utm_source=tiktok&utm_medium=bio&utm_content=TS-1`. Followers are observed, never
targeted — same rule as `account-launch-plan.md` §5.1, and it matters more here because TikTok reach
is national while the product serves a 2km radius.

**The kill criterion:** if two consecutive slideshows land under 20% 완주율, the problem is slide 1,
not the channel. Rewrite hooks before making more.
