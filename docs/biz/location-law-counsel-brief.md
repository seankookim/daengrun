# 위치정보법 검토 요청 — 댕런 (반려견 러닝 매칭 서비스)

**작성 2026-08-15 · 변호사 상담용 1장 요약 · 문의: 김세안 (창업자)**

## 서비스 개요
보호자가 앱으로 러너(달리기 대행인)를 예약하면, 러너가 보호자의 반려견을 데리고 달립니다.
서울 반포 일대 파일럿 준비 중이며 **아직 정식 출시 전**입니다. 현재 실결제 없음(무료 파일럿),
법인/사업자 등록 준비 단계.

## 위치정보 관련 사실관계 (기술적으로 확인된 내용)
1. **러닝 중 러너의 GPS 위치를 수집**합니다. 화면이 꺼져 있어도 기록되도록
   **백그라운드 위치 권한**(iOS `location` background mode)이 앱에 설정되어 있습니다.
2. 수집된 위치는 서버(Supabase)로 전송되어 저장되며, **보호자에게 실시간
   지도로 러너의 현재 위치와 이동 경로가 표시**됩니다.
   ⚠ **데이터 저장 위치는 국내입니다.** 프로젝트 리전은 `ap-northeast-2`(AWS 서울)로
   측정 확인했습니다 — 이 문서의 이전 판은 "해외 리전"이라고 적었으나 **사실과 다릅니다**.
   다만 **저장 위치(국내)와 처리자의 국적(Supabase Inc., 미국 법인)은 별개의 사실**이므로
   두 가지를 모두 전달합니다. 국외이전(개인정보 보호법 제28조의8) 해당 여부는 변호사님의
   판단이 필요한 지점이며, 저희가 "국외이전이다/아니다"를 단정하지 않습니다.
3. 러너는 회원가입한 **특정 개인**(식별된 자연인)입니다. 즉 "식별되는 개인의 위치정보"입니다.
4. 러닝 종료 후 이동 경로(좌표열)는 서버에 보관됩니다. 코스로 공개될 때는 시각 정보를
   제거한 좌표만 사용합니다(누가 언제 어디 있었는지는 공개 안 됨).
5. 현재 동의 절차: **OS 권한 팝업뿐**입니다. 위치정보 수집·이용에 대한 별도 동의서,
   위치기반서비스 이용약관, 개인위치정보 처리방침은 **아직 없습니다**.
6. 방송통신위원회(KCC) **위치기반서비스사업자 신고: 미신고** 상태입니다.

## 질문 (우선순위 순)
1. 위 서비스 형태가 **위치기반서비스사업자 신고 대상**인지, 신고가 **서비스 개시 전**
   완료되어야 하는지. (파일럿/무료/소규모라도 예외가 없는지)
2. 신고 대상이라면: 절차, 소요 기간, 필요 서류, 그리고 **사업자등록·법인 설립과의 선후 관계**.
3. OS 권한 팝업 외에 **별도의 위치정보 수집·이용 동의**와 **위치기반서비스 이용약관**이
   필요한지, 필요하다면 최소 요건.
4. 러너(위치정보 주체)와 보호자(열람자) 관계에서 추가로 요구되는 고지·동의가 있는지.
5. 미신고 상태로 파일럿을 진행할 경우의 **법적 리스크 수준**(형사처벌 여부 포함).

## 함께 여쭤볼 별건 (결제 관련, 1문항)
자동결제(빌링키) 도입 시, **결제 전 사전 고지 의무**(금액·시기 통지)의 구체적 요건 —
전자상거래법/여신전문금융업법상 무통보 자동결제가 허용되는 조건이 있는지.
