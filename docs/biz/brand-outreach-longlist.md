## Verification standard (read this first)

The prior sweep put two brands into our docs — **페티즌** and **댕러민** — that **do not exist**. That failure mode is now designed out:

| Mark | Meaning |
|---|---|
| **V1** | I fetched the brand's **own live site** this session and read company name / CEO / 사업자등록번호 / address / contact off it. Strongest. |
| **V2** | Own site confirmed live but robots-blocked or JS-only; identity confirmed via a **second independent source** (dated news article, exhibitor list, retailer brand page, official Instagram). |
| **V3** | No own-site read. Existence confirmed only via **retailer brand pages / dated news**. Usable, but confirm before pitching. |
| **ANNEX** | Named somewhere but **not verified** — see §11. Do not pitch. |

Other marks: **🏙** = Seoul/수도권 HQ (event-logistics advantage) · **★** = documented 체험단 / 서포터즈 / 인플루언서 / 제휴 program (= receptive to this class of pitch) · **B2B** = published wholesale or partner storefront.

**Deal rungs:** R1 = event/club-run sponsorship · R2 = in-app placement / paid mid-run sampling with photo proof · R3 = affiliate or promo code · **DIST** = distribution / stock relationship.

**No contact information in this document was invented.** Where only a general CS or data-protection address exists, it is flagged as such.
