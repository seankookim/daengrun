결론: **토스페이먼츠 결제위젯** (카카오페이·네이버페이·카드 모두 위젯 안에서 해결).

## 통합 아키텍처 (코드 준비 완료 지점)
1. 클라: request pay → 토스 결제위젯 (RN: `@tosspayments/widget-sdk-react-native`, 네이티브 리빌드 동승)
2. 성공 콜백 → 새 Edge Function `confirm-payment`: 토스 승인 API 검증(secret key, 서버만)
   → 금액 = bookings.total_price 대조 (클라 금액 불신 원칙 유지) → `payment_ok` 전이
3. 취소/환불: cancel_owner의 fee 계산 → 토스 부분취소 API
4. 러너 정산(지급)은 별도 트랙: 오픈뱅킹/펌뱅킹 또는 수기 이체 (파일럿은 수기 + ledger_items 대조)
