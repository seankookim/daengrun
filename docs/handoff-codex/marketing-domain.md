## 5. Traps that would cost a stranger a day

1. **The source assets are OUTSIDE the repo and unversioned** — `/Users/sean/Desktop/post`, 67 PNGs. Rendered outputs
   are committed; the source plates are not. If that folder moves, every asset reference and both boards' regeneration
   break. `check-campaign-refs.py` fails loudly if it happens.
2. **Logo contamination is invisible at thumbnail scale.** Several assets carry a **Nike swoosh**; the first style
   anchor looked clean on a contact sheet and had one on the shoe at 100%. Inspect at full resolution. Treat `dumb/`
   as a reject bin.
3. **THREE palettes exist and only one is current.** `rebrand.md` (volt/forest) is superseded; `DESIGN.md`/`theme.ts`
   (lilac bg, coral `#FF5C3D`, violet `#7B6CDF`) wins per CLAUDE.md; produced assets are coral-red + violet +
   volt-on-the-dog. **Never paste `prompt-library.md`'s BASE DNA together with `generation-prompts.md`'s ACCENT LAW** —
   the former is volt/forest-era. Its §1.2 treatments and §2 negatives remain good.
4. **The documented launch grid keys to assets that were never produced** (`IMG-A1`–`IMG-D1`);
   `instagram-preorder-campaign.md` §1 is the recut that uses real files.
5. **Black Han Sans is not installed on this machine.** Every rendered post uses Apple SD Gothic Neo Bold as a
   labelled stand-in; re-render is one command (`docs/labs/build-posts.py`).
6. **Arial Black has no `₩` glyph** — it rendered tofu on the runner pay card, the one card whose whole job is showing
   the real number. Fixed for that glyph; the class recurs with any new font.
7. **`.claude/` is gitignored and the brand voice file is force-added past it.** A `.gitignore` tightening or a
   careless `git clean` loses the file the brand-voice skill reads.
8. **Runner pay is governed by the 33% take rate** (`runner-recruitment.md` §1, migration 0059): 5 km ₩16,683 /
   7 km ₩20,703. **"2만원대" is the OWNER price anchor and must never be said to runners.** If the take rate moves,
   pull published posts *before* editing numbers.
9. **ID namespaces collide across four documents**: concepts `C1`–`C10`, franchises `F1`–`F6`, reels `R1`–`R8`,
   images `IMG-A1`–`IMG-M*`, and this session's `P1`–`P12` / `V1`–`V6` / `TS-1`–`TS-6`. Bare `C1` is ambiguous and has
   already caused a mis-order once.
10. **Three claims are load-bearing on every campaign surface** and each would be a lie if copied from the older
    external docs: 바디캠 has no pipeline (`app/app/owner/schedule.tsx:498` is the app's only forward-looking line);
    `app/src/lib/api.ts:383` hardcodes `identity_verified: false`, so say "인증 러너", never "신원인증"; and there are
    **zero customers**, so no testimonial, rating or user count anywhere. `check-campaign-refs.py` re-verifies all
    three against the code on every run.
