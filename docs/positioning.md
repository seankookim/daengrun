# 댕런 포지셔닝: 반려견 피트니스

> 결정 (2026-07-21): 댕런은 산책 대행이 아니라 **반려견 피트니스** 카테고리를 만든다.
> 마케팅에서 "산책"이라는 단어를 쓰지 않는다. 산책은 비포펫이 가져가게 둔다.

## 한 줄

**"산책으론 부족한 개들이 있다."**
댕런은 에너지 넘치는 반려견에게 진짜 운동을 시켜주는 러닝 매칭 서비스.

## 카테고리 비교

|  | 비포펫 (산책 대행) | 댕런 (반려견 피트니스) |
|---|---|---|
| 파는 것 | 집안일 대체 (배변, 기본 자극) | 운동 결과 (지친 개, 건강한 개) |
| 고객 감정 | 불편함 해소 | 죄책감 해소 ("우리 애 운동 못 시켜줘서") |
| 가격 앵커 | 30분 9,900원, 업계 최저가 | 회당 2만원대, 프리미엄 |
| 공급자 | 이웃 산책 도우미 (부업 긱워커) | 러너 (러닝크루 문화, 본인 훈련 겸 수익) |
| 기록 | 사후 리포트 | 실시간 GPS + 바디캠 라이브 + Strava식 기록 |
| 정체성 | 케어 서비스 | 피트니스 커뮤니티 |

## 타깃

- **1차 (수요)**: 고에너지 견종 보호자 — 보더콜리, 웰시코기, 리트리버, 진도믹스, 셰퍼드, 허스키, 비즐라 등. 풀타임 근무. "우리 애는 산책으론 안 빠져요"라고 말해본 사람.
- **1차 (공급)**: 20-30대 러너. 러닝크루 활동, Strava 사용. "어차피 뛰는 거 개랑 뛰고 돈 받자."

## 왜 지금

- 서울 러닝크루 붐 = 공급 풀이 역대 최대
- 비포펫이 "앱으로 낯선 사람에게 개 맡기기"를 시장에 학습시키는 중 (우리 대신 비용 지불)
- 1인 가구 + 대형견/활동견 입양 증가, 운동 부족은 문제행동의 최대 원인

## 모트 (베낄 수 없는 것)

기능은 베껴진다 — 비포펫이 "러닝 티켓"을 내는 데 한 분기면 충분하다. 우리가 쌓는 것:

1. **러너 브랜드/커뮤니티**: 댕런 러너라는 정체성. 기록, 스트릭, 랭킹, 크루 문화. 긱워커 풀에는 없는 자부심.
2. **개 피트니스 데이터**: 견종별 페이스, 회복, 누적 거리 — "우리 개 심박은 정상인가?" 를 답할 수 있는 유일한 서비스.
3. **라이브 신뢰 스택**: GPS + 바디캠 실시간. 사후 리포트가 아니라 라이브.

## 메시징 규칙

- 쓰는 말: 러닝, 운동, 페이스, 기록, 체력, 크루, 피트니스
- 안 쓰는 말: 산책, 대행, 돌봄, 시터
- 가격 대화가 나오면: "산책 대행이랑 비교하면 비싸요. PT랑 비교하면 싸고요."

## 리스크 (정직하게)

- **니치의 니치 리스크**: '운동 부족 고민 + 지불 의사' 교집합이 작을 수 있다 → 인터뷰 15-20건으로 검증 (validation-interviews.md)
- 여름 폭염/겨울 한파 = 계절성. 새벽/야간 슬롯, 실내 대안 고민 필요
- 개 러닝 안전 (슬개골, 발바닥 화상, 과체중견) → 러너 교육 커리큘럼이 오히려 신뢰 자산이 됨
