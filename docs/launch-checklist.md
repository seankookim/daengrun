## 0. 임계 경로 (솔직하게)

법률도 스토어도 오늘 실고객을 막는 항목이 아니다. **실제로 막는 것은 두 가지:**

1. **인증 러너가 생길 수 없다** — `/runner/apply`는 안내 화면이고 제출 버튼이 없다. CTA는
   `/settings`로 간다. applicant → certified 승급 경로가 서버 어디에도 없다. 그런데
   `transition-booking:103`은 `tier === 'applicant'`의 오픈 요청 수락을 403으로 막고,
   `api.ts:543`은 러너 목록에서 applicant를 제외한다 → **보호자에게 보이는 러너 목록은
   구조적으로 비어 있다.** [검증됨]
2. **GPS가 잠금화면에서 죽는다** — `geo.ts:23`은 `requestForegroundPermissionsAsync` +
   `watchPositionAsync`뿐. 백그라운드 권한도 `UIBackgroundModes`도 TaskManager도 없다.
   러너가 화면을 끄면 거리 측정이 멈춘다 — 제품의 핵심 약속이 깨진다. [검증됨]

나머지는 50마리 파일럿 한정으로 우회로가 있다. 이 둘은 없다.

**최단 경로 (사업자등록 없이 유지 → 예창패 2027 살림):**
인터뷰 → 러너 지원 플로우 → 백그라운드 GPS → 수기 결제 브리지 → 위치정보 신고 + 개인정보처리방침
→ TestFlight.

### 왜 파일럿에 앱스토어가 필요 없나
iOS 공개 배포 경로는 앱스토어뿐이지만, TestFlight 외부 테스트는 공개 링크로 최대 1만 명까지
가능하고 심사는 가벼운 Beta App Review다. 반포 파일럿(보호자 50 + 러너 22 ≈ 72명)은 전부 커버된다.
대가: 빌드 90일 만료, 테스터가 TestFlight 앱 설치 + 초대 수락을 거쳐야 함(전환 마찰),
검색 노출 없음(어차피 수기 모집이라 손실 없음).

### 애플 30%는 해당 없음
반려견 러닝은 실물 세계에서 제공되는 서비스 → 우버·배민과 같은 분류로 인앱결제 의무 대상이 아니다.
토스 등 자체 결제 수단을 그대로 쓰면 된다.
