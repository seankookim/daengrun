# 리브랜드 — 도그스하이 (2026-07-28)

댕런은 타사 사용 중 확인(마케팅 리서치 세션) → 리네이밍. 방향 = **비주얼 리프레시** (volt×forest DNA 유지, 토큰 재보정).

## 이름: 도그스하이 (DOGS HIGH)
- 근거: **러너스하이(러-너-스-하-이)와 5음절 1:1 미러** — 러닝 크루 타깃에게 설명 없이 통하는 인용. 독스하이(4음절)는 운율이 깨져 탈락, 하이테일은 영어 원어민용 워드플레이라 탈락.
- '하이' = 히어로 음절이자 시스템 생성기:
  - **하이 포인트** (구 댕마일 — UI 라벨만, DB `miles_ledger`·서버 로직 불변)
  - **하이 찍다** = 러닝 완료의 동사 (도장 문화와 같은 어법)
  - **하이파이브** (인계 의식) · **오늘의 하이** (공유 카피) — 아직 미적용, 아래 '보류' 참조
- 락업: 도그스(화이트) + 하이(volt). 축약 표면(아이콘·좁은 UI)은 '하이' 단독.
- ⚠ **커밋 전 필수**: KIPRIS(도그스하이·DOGS HIGH, 반려동물 서비스류) + 앱스토어 + @dogs.high / dogshigh.run

## 디스플레이 서체 — Black Han Sans
- `src/lib/displayFont.ts` `useDisplayFont()` — 지연 로드, 미설치 시 시스템 900 폴백 (크래시 없음).
- **Sean: `cd app && npx expo install expo-font @expo-google-fonts/black-han-sans`** (JS 로드 — 리빌드 불필요, Metro 재시작만).
- 적용 규칙: 화면당 1회. 현재 적용: 로그인 워드마크, 홈 find-now 히어로 타이틀, find-now 시트 타이틀. 확산은 화면 보며 점진.

## 앱 아이콘 — 옵션 A (풀블리드 저스티파이드 스택)
- `app/assets/icon.png` 교체 (1024, 도그스/하이 2단 — 실 Black Han Sans 렌더). 원본: `docs/brand/dogshigh-icon-a-1024.png`.
- 반영은 `prebuild --clean` + `run:ios` (대기 중인 리빌드에 동승).
- 스토어 1024·마케팅용 = B안(스택+마스코트), 대체 아이콘 후보 = D('하이'+마스코트)·F('하이' 솔로) — icon lab 참조.

## 마스코트 (2차 스케치 단계 — 미구현)
- 원칙: **개를 칠하지 말고 입혀라** — 크림 진돗개 + volt 반다나 (volt 털 = 고블린 사고, 부검 완료).
- 구역: 빈 상태·온보딩·스탬프·에러·마케팅만. 실사진 구역(히어로 링·순간 스트립·리포트·피드·신뢰 표면) 불가침.
