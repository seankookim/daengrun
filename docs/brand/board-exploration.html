솔직한 트레이드오프

① 헤리티지 클럽

티어·빕·기록부 — 기존 세계관(러너 티어, 개인 기록 배지)과 서사가 정확히 맞물림
샵/장비 경제와 최고 궁합 — '클럽 용품점'은 커머스에 명분을 준다
'피트니스 테크' 신뢰(GPS·실시간·데이터)가 빈티지 톤에 묻힐 수 있음
volt 포기 = 기존 자산 리셋 비용 최대
어울리는 순간: 브랜드를 커뮤니티/멤버십으로 키울 때

② 나이트 서킷

volt를 버리지 않고 의미를 강화 — 자산 연속성 있음
라이브 트래킹·페이스·Live Activity 등 실기능이 이미 이 인격
전 화면 다크 커밋 필요 — '반쪽 다크' 사고의 교훈상 비용이 가장 큼
보호자(구매자)의 정서적 니즈('아이를 맡긴다')엔 차가울 수 있음
어울리는 순간: 러너(공급자) 브랜드로 분리하거나, 나이트 테마를 서브 브랜드로

③ 소프트 조이

응가 도장·댕마일·피드 자랑 — 기존 장치들이 이미 이 언어를 쓰고 있음
한국 펫 시장 정서 적합도 최고, 바이럴(공유 카드) 잠재력 최대
'운동 결과를 판다'는 차별화(비포펫과의 거리)가 산책 대행처럼 뭉개질 위험
신뢰 표면(결제·안전)과 톤 충돌 — 이중 톤 운영 규칙이 필수
어울리는 순간: 보호자 그로스에 올인할 때 — 단 데이터 서사는 지켜야 함
