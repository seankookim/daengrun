무엇이 달라졌나

Clay 뉴트럴 층. 흰 카드와 크림 배경 사이에 웜 뉴트럴이 한 층 생겨 칩·웰이 하얗게 떠 보이지 않는다.
디스플레이 서체. find-now 타이틀·화면 제목이 Black Han Sans로 — '앱 UI'에서 '러닝 클럽 포스터'로 톤이 이동.
토큰 미세 보정. forest는 더 깊게, volt는 크림 위에서 더 정확하게, coral은 더 펀치 있게 — 코드에선 theme.ts 여섯 줄.
레이스 빕 모티프 승격. 오늘 만든 빕 필을 브랜드 전체 모티프로 — 리포트 공유 카드, 러너 프로필, 샵 배지까지 같은 언어.
마이그레이션 비용: theme.ts 토큰 6줄 + 디스플레이 폰트 1종 번들 + 워드마크 에셋 교체. 레이아웃 변경 없음.
모든 사진 자리는 실사진(강아지 프로필·runs.photos)이 채운다 — 이 보드의 이모지는 자리 표시일 뿐, 앱에는 스톡/일러스트를 넣지 않는다 (정직 원칙 유지).
