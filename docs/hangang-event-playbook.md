# Han River Event Playbook — 도그스하이 크루 (Saturday)

*Drafted 2026-07-30. This is Phase 2's flywheel event from docs/marketing-fundraising.md §3, expanded to operational detail. One event, four jobs: recruit runners, convert owners, generate a week of content, build the local-monopoly feel.*

---

## 0. Format

**Every Saturday morning, same 한강공원 section (launch 동), same time.** Consistency is the product — "토요일 아침엔 도그스하이" must become a neighborhood fact. Summer schedule 07:00–09:00 (heat-index rule below), spring/fall 08:00–10:00.

Core program (90 min):

1. **07:00 체크인** — bib pickup (dog bibs, volt), waiver, dog meet-and-sniff buffer.
2. **07:20 그룹 러닝** — 2–3 pace groups (walk-jog / 5:30+ / open), certified runners lead, owners run with their own dogs. 3km loop, fixed course.
3. **08:00 체력나이 측정 부스** — the conversion engine. Dog gets measured (the app's 체력나이 chip), owner gets the shareable card on the spot + QR to the founding-member offer.
4. **08:20 피니셔 세리머니** — every dog gets a finisher photo delivered same-day (this is the NPS moment), leaderboard reveal on the portable screen, treats table.

## 1. Permits — do this first

- 한강공원 place-use goes through **서울시 미래한강본부** — there is a formal **[장소사용 (체육·일반) 신청](https://hangang.seoul.go.kr/www/contents/886.do?mid=883)** process with published approval conditions, plus a [민원신청 종합안내](https://hangang.seoul.go.kr/www/contents/845.do?mid=622) page listing application types.
- Practical read: a booth, banners, a screen, and a treats table = an event needing approval; a plain group run on public paths generally doesn't. **So week 1–2 can run permit-free (group run + handheld photos only)** while the 장소사용 application for the full booth format clears. Budget 2–3 weeks lead time and apply for a recurring slot if the office allows it.
- Verify on the site before applying — conditions, section-office contacts, and fees vary by 공원 section (반포/잠원/뚝섬 etc.). Dogs: leash rules always; check the section's pet-area rules so the booth sits where dogs are unambiguously allowed.
- Insurance: event-day liability cover on top of per-run cover. One dog-fight incident at our own branded event is the nightmare scenario — meet-and-sniff buffer, spacing between pace groups, and a no-retractable-leash rule are safety *and* brand.

## 2. Sponsor pitch (make the event free)

Target: Korean treats/gear brands + one local vet clinic per event. The ask is small and the offer is sharp:

> "매주 토요일, 같은 자리, 반려견 보호자 30–60명 — 전원 고관여 (직접 뛰러 나온 사람들). 간식 테이블 스폰서: 제품 제공 + ₩200k, 부스 사이드 노출 + 전 참가견 피니셔 포토에 로고 + 릴스 태그."

- Weekly recurring beats one-off festivals for a brand — 4 slots/month, sell 2, keep 2 for rotation.
- Vet clinic partner: staffs the 체력나이 booth once a month ("수의사 자문 운동 프로토콜" credibility), gets its poster/QR into the booth — this is the trust-infrastructure collab, not commerce.
- Effect on model: sponsor coverage takes event cost from ₩400k → ~₩150–200k (Assumptions!B28 in the growth model — update when real).

## 3. The portable leaderboard (jumbotron energy, popup budget)

Stage 1 of the Ready-Player-One idea:

- **Kit**: 43–55" high-brightness portable display or short-throw projector + white board (morning light: LED panel wins), battery station, tripod stand. Rented ~₩150–250k/event or bought used ~₩600–900k once (buy after week 3 if the event sticks).
- **Content loop** (already app-adjacent, volt-on-forest): weekly distance leaderboard (dog name + breed + km), 체력나이 개선 랭킹, live check-ins as dogs finish, "이번 주의 하이" photo.
- **Shoot it like it's huge.** Low-angle shots with dogs in front make a 50" panel read as a stadium screen on Reels. The *photo of the leaderboard* is the asset; the physical object is a prop.
- Stage 2 (month 3+): 명예의 전당 print board inside partner vet clinic/유치원 — permanent physical presence, zero permits. Stage 3 (post-funding): the real jumbotron as a one-off PR stunt with press invited.

## 4. Run-of-show ownership (2-person operation)

| Time | Person A (founder) | Person B (runner-staff) |
|---|---|---|
| 06:15 | Booth, screen, banner setup | Course markers, water, treats table |
| 07:00 | Check-in + waivers + bibs | Dog buffer zone, pace-group sorting |
| 07:20 | Sweeper + camera (bodycam POV) | Lead pace group |
| 08:00 | 체력나이 booth + founding-member QR pitch | Finisher photos (every single dog) |
| 08:40 | Leaderboard ceremony, sponsor shoutout | Treats table |
| 09:00 | Teardown | Same-day photo delivery batch |

Same-day finisher-photo delivery is non-negotiable — it's the NPS trigger and the review-ask moment ("사진 마음에 드시면 카페에 후기 한 줄만…" — see Naver cafe plan §3).

## 5. Content capture plan (one event = one week of feed)

Shot list per event: dog-POV bodycam of the group run (1 reel) · before/after zen-dog of one featured dog (1 reel) · leaderboard reveal low-angle (1 reel) · 체력나이 card close-ups (stories) · runner-dialect crew shot (1 recruitment post) · finisher photo set (owner-shared UGC, tag mechanic: bib number + @dogs.high).

## 6. Metrics per event

Attendance (dogs) · first-timers vs repeats · 체력나이 measurements taken · founding-member QR conversions · same-day photo delivery rate (target 100%) · UGC posts tagged · incident count (**must be 0**). Decision rule from the playbook stands: this event's CAC (booth conversions ÷ event cost) should beat every paid channel — the growth model says ~7x LTV:CAC at base assumptions; verify against reality by week 6.
