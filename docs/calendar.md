# 캘린더 · 예약 시스템 설계 (2026-07-22 확정)

## 내비게이션 결정

역할별로 캘린더 접근이 다르다 — 보호자는 가끔 예약하고, 러너는 일정이 곧 일이다.

- **보호자 탭**: 홈 · 커뮤니티 · 기록 · 샵 · **마이** (캘린더 탭 없음)
  - 예약 진입: 홈 CTA "러닝 요청하기" + 홈 일정 위젯 → 전체 일정
  - 안심 센터: 마이 안에 + 홈 퀵카드 + 라이브 화면 SOS 버튼 (안전은 러닝 중이 가장 중요)
- **러너 탭**: 홈 · **캘린더** · **요청** · 수익 · 마이
  - 커뮤니티는 홈에서 진입 (러너 정체성/스트릭은 모트지만 업무 중 빈도는 낮음)

## 홈 일정 위젯 (보호자) — 상태 4개, 컴포넌트 1개

1. **빈 상태**: "예정된 러닝이 없어요" + 러닝 예약하기 + 반복 일정 만들기
2. **예정**: 다음 러닝 시간·강아지·러너·픽업·카운트다운·채팅·일정 변경·전체 일정
3. **매칭 대기**: 결제 완료, 러너 응답 대기 표시
4. **라이브**: 경과 시간·현재 거리·맵 프리뷰·실시간 보기 (라이브 카드로 변신)

## 예약 흐름 결정: 7단계 아님

기존 원스크린 요청 화면 유지 (강아지/거리/페이스/시간/픽업/옵션 + 실시간 가격).
추가할 것은 **일정 방식 + 날짜·시간 슬롯 선택 바텀시트**뿐:

- 방식: 가장 빠른 시간 / 날짜·시간 선택 / 반복 예약 / 러너 캘린더에서 선택
- 슬롯: 가로 날짜 스트립 → 오전/오후/저녁 그룹, 공급 신호 ("러너 8명 가능", 인기 시간, 할인), 불가 슬롯은 비활성으로 표시

## 목업 단계 핵심 화면 10개 (나머지는 전부 이 화면들에서 파생)

1. 홈 일정 위젯 (4상태 = 1컴포넌트)
2. 보호자 내 일정 — 아젠다 뷰 (기본)
3. 날짜·시간 슬롯 바텀시트
4. 예약 상세 (상태별 섹션 변화)
5. 반복 예약 설정
6. 러너 캘린더 — 데이 타임라인
7. 러너 주간 가용시간 편집기
8. 러너 요청 인박스
9. 오버레이: 슬롯 홀드 카운트다운
10. 오버레이: 시간 충돌/이동시간 부족 경고

## 예약 상태 머신 (백엔드 = Supabase 스키마의 씨앗)

```
Draft → Quoted → Payment Hold → Matching → Runner Pending
→ Confirmed → Runner En Route → Picked Up → Active → Completed
```

대체 상태: Cancelled by Owner / Cancelled by Runner / Expired / No Show / Incident Review / Refund Pending

상태 색: 확정=포레스트, 러너 대기=앰버, 결제 대기=뮤트블루, 러닝 중=라임+LIVE, 완료=세이지, 취소=그레이, 문제=코랄

## 가용성 엔진 — 슬롯이 예약 가능한 조건 (전부 서버 계산)

러너 가용 ∧ 확정 예약 무중복 ∧ 홀드 무중복 ∧ 이동시간 확보 ∧ 휴식 버퍼 확보
∧ 견종/크기 수락 ∧ 페이스 역량 일치 ∧ 서비스 반경 내 ∧ 그룹 정원 여유 ∧ 정책(날씨 등) 통과

**더블부킹 방지**: 결제 진입 시 슬롯 임시 홀드(~5분) → 타 사용자에게서 제거 → 결제 → 원자적 확정 → 실패 시 해제.

**시간 처리**: UTC 저장, Asia/Seoul 표시, 공휴일 처리, 반복 규칙에 타임존 부착.

**이동 버퍼**: 이전 세션 종료 지점 → 다음 픽업 이동시간 + 장비/인계 버퍼. 부족 시 러너 캘린더에 "이동 시간이 12분 부족해요" 경고.

## 반복 예약 (구독 매출의 전 단계 — km 크레딧과 페어링)

주간/요일 선택/격주/커스텀 · 종료일 또는 횟수 · 동일 러너 우선/대체 허용 · 공휴일 스킵
· 시리즈 일시정지 · 1회만 수정 · 이후 전체 수정 · 1회 취소 · 시리즈 취소.
단일 회차 수정이 시리즈를 파괴하지 않을 것.

## 러너 가용시간

- 주간 반복: 요일별 복수 시간대, 다른 요일로 복사, 최소 통보 시간, 최대 예약 거리, 하루 최대 세션, 세션 후 필수 휴식, 그룹 정원
- 예외: 휴가/개인 일정/임시 휴무/날씨 제한/특정일 연장 근무
- 외부 캘린더(Apple/Google) 연동: 외부 일정은 가용성만 차단, 내용은 비공개 — 후순위

## 단계별 계획

1. **Phase 1 (목업)**: 핵심 10화면 — ChatGPT 목업 도착 시 배치별 구현
2. **Phase 2**: 반복/변경/취소/휴무 심화
3. **Phase 3**: 엣지 상태 (결제 실패, 매칭 만료, 날씨, 대체 러너)
4. **Phase 4**: Supabase에 상태 머신 + 가용성 엔진 실구현
